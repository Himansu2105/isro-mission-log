# 🚀 ISRO Mission Log

An interactive web-based **ISRO Mission Log** designed to explore, manage, and visualize Indian space missions through a clean mission-control-inspired interface.

The application allows users to browse missions, search and filter mission records, view detailed mission information, and add, edit, or remove missions from the log.

---

## ✨ Features

- 🚀 **Mission Dashboard** — View total, active, completed, and planned missions.
- 🔎 **Search Missions** — Search by mission name, launch vehicle, or payload.
- 🗂️ **Category Filtering** — Filter missions by categories such as:
  - Earth Observation
  - Communication
  - Navigation
  - Lunar
  - Interplanetary
  - Astronomy
  - Human Spaceflight
  - Technology Demo
- 🟢 **Status Filtering** — Filter missions by Planned, Active, Completed, or Failed status.
- 📋 **Mission Details** — View vehicle, launch date, launch site, payload, objectives, and mission logs.
- ➕ **Add Mission** — Create and log a new mission.
- ✏️ **Edit Mission** — Update existing mission information.
- 🗑️ **Delete Mission** — Remove missions from the log.
- ⭐ **Flagship Missions** — Mark important missions as flagship missions.
- 🛰️ **Rocket Specifications** — View rocket/launch vehicle information.
- 🕐 **Live IST Clock** — Displays the current Indian Standard Time.
- 📱 **Responsive UI** — Designed to work across different screen sizes.
- 🎨 **Mission Control Theme** — Space-console-inspired interface with scanline and telemetry-style visuals.

## 🎮 How to Use

### Search

Use the search bar to find missions by:

- Mission name
- Launch vehicle
- Payload

### Filter

Use the status buttons or category dropdown to narrow down the mission list.

### Add a Mission

Click:

```text
+ LOG NEW MISSION
```

Enter the mission information and select **Commit to Log**.

### View Mission

Click on a mission to open its detailed mission log.

### Edit or Delete

From the mission details, you can edit the mission or remove it from the log.
